Detailed Description

Description: A drop-down list: a box that shows the item chosen, and the list of items that opens under it when the box is clicked. Choosing an item in the list, with the mouse or the keyboard, changes the selection and calls OnSelectionChanged, the virtual to override to do something about the change.

The open list is drawn over every other user interface object and over the edges of the grid the drop-down sits in. While it is open it has the mouse to itself: a click on an item chooses it, and a click anywhere else in the view closes the list and goes no further. The mouse wheel scrolls a list that is longer than MaximumVisibleItems.

The keyboard, once the drop-down has focus: Up and Down, Home and End move through the items - choosing as they go when the list is closed, the way a combo box in a dialog does, and only moving the highlight when it is open. Alt+Down, F4 or Space opens the list; Enter or Space chooses the highlighted item, Escape closes the list without changing anything and Tab moves on. A letter goes to the next item that starts with it.

The box shows the selected item, or the placeholder text when nothing is selected. CRhinoUserInterfaceControl::Text is not used.

◆ IsListOpen()

bool CRhinoUserInterfaceDropDown::IsListOpen ( ) const

Description: Is the list open? OpenList opens it in the view the drop-down was last drawn in, or in the active view before it has been drawn, and returns false when the drop-down is hidden or has no items. Only one list is open at a time: opening one closes any other. CloseList closes it without changing the selection.
