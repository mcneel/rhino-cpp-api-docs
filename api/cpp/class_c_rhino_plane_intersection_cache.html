Detailed Description

Description: Data that RhinoIntersectPlaneGeometry computes from the geometry alone, kept between calls: the mesh intersection cache of a mesh, and the brep a SubD, extrusion, surface or brep face converts to. Reuse one cache for many planes through the same geometry, such as a contour stack. Remarks: Entries are keyed by the address of the geometry. The cache must not outlive the geometry it was used with. Call Clear() when that geometry is changed or deleted; not while it is in use. One cache can be used from several threads at the same time.
