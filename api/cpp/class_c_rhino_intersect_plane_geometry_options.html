◆ m_bIncludeHiddenObjects

bool CRhinoIntersectPlaneGeometryOptions::m_bIncludeHiddenObjects = false

If false, the objects of an instance definition that are hidden or on a layer that is off are skipped, as the Contour command does. Nested instance references are entered whether they are visible or not, and their objects are tested one by one.

◆ m_bJoinCurves

bool CRhinoIntersectPlaneGeometryOptions::m_bJoinCurves = true

If true, join the resulting curves of each object where possible, for every geometry type. Curves of different objects, such as the objects of an instance definition, are never joined. True is the behavior of RhinoIntersectPlaneBrep.

◆ m_bPointCloudAsPoints

bool CRhinoIntersectPlaneGeometryOptions::m_bPointCloudAsPoints = false

If true, every point of a point cloud or point grid within tolerance of the plane is returned in points. If false, they are returned as one polyline in curves, as the Contour command does.

◆ m_terminator

ON_Terminator* CRhinoIntersectPlaneGeometryOptions::m_terminator = nullptr

Optional. Checked between the objects of an instance definition, in point clouds and in mesh intersections. A single brep intersection cannot be cancelled once it has started.

◆ m_xform

ON_Xform CRhinoIntersectPlaneGeometryOptions::m_xform = ON_Xform::IdentityTransformation

Maps the geometry to the space of the plane and the results, as ON_InstanceRef::m_xform does. Avoids transforming a copy of the geometry. Must not be singular.
